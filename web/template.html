Flashlight + translator

The input is blurred so that nothing above 0.25 cycles/pixel survives. Any Fourier gain on that input writes exactly zero there. The writers below regrow that dark band from the octave below: the amplitude of the parent band says where (flashlight), its phase says what (translator). All weights were fitted offline by least squares and are embedded in this page. Honest result: on hard-edged scenes it regrows most of the dark band; on held-out photographs it does not beat writing nothing.

What the flashlight sees

Scores are R² on the 208 × 208 interior, against the true band. Dark-band R² = 0 means "wrote nothing useful"; negative means it wrote the wrong thing. Controls: negate flips the image — an odd writer flips with it and keeps its score, the even writer cannot. Phase twin keeps every Fourier magnitude and scrambles the phases, so cross-scale phase coupling is gone. Shift parent computes the features correctly but rolls them 64 × 96 pixels before writing.
